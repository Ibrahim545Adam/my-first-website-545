# My First Website — My Beginning in Web Development

This repository contains my first website project, created while learning the fundamentals of frontend web development.

It represents an early stage of my journey into building websites and experimenting with HTML and CSS.

## 🎯 Project Overview

The project was created to practise building a basic webpage, organising content and applying styles.

The Barcelona image included in the project was used as sample content for practice purposes. The website is not an official Barcelona fan page.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📚 What I Practised

- Creating a basic HTML document.
- Working with headings, paragraphs and images.
- Connecting an external CSS stylesheet.
- Applying basic website styling.
- Organising project files.
